# CoinRush

제한 시간 내에 코인을 가장 많이 수집한 플레이어가 승리하는 멀티플레이 레이싱 게임입니다.

## 🎮 프로젝트 소개

CoinRush는 Unreal Engine 5를 기반으로 개발한 멀티플레이 레이싱 게임입니다.

플레이어는 제한 시간 동안 맵 곳곳에 배치된 코인을 수집하며 경쟁합니다. 공격과 지뢰를 활용해 상대 플레이어를 견제할 수 있으며, 속도 증가 아이템을 획득해 더욱 빠르게 코인을 모을 수 있습니다.

제한 시간이 종료되면 코인 수집량을 기준으로 우승자를 결정합니다.

## ✨ 주요 기능

- **멀티플레이 레이싱**: 여러 플레이어가 동시에 레이싱을 진행하며 코인 수집 경쟁을 펼칩니다.
- **코인 수집 시스템**: 맵에 배치된 코인을 획득하여 코인 수집량을 늘립니다.
- **공격 시스템**: 상대 플레이어를 공격해 코인 수집 경쟁에서 우위를 확보합니다. 공격 대상이 일정량 이상의 코인을 보유한 경우, 공격자는 코인을 획득하고 피격자는 코인을 잃습니다.
- **지뢰 설치 시스템**: 지뢰를 설치해 상대 플레이어의 주행을 방해합니다.
- **속도 증가 아이템**: 보너스 아이템을 획득해 일정 시간 동안 주행 속도를 증가시킵니다.
- **제한 시간 및 승리 판정**: 제한 시간이 종료되면 플레이어별 코인 수집량을 기준으로 우승자를 결정합니다.

## 🛠️ 개발 환경

- **게임 엔진**: Unreal Engine 5
- **프로그래밍 언어**: C++
- **버전 관리**: Git, GitHub

## 🚀 실행 방법

1. GitHub 저장소를 Clone합니다.
2. Unreal Engine 5에서 `.uproject` 파일을 엽니다.
3. 필요한 경우 프로젝트를 빌드합니다.
4. 멀티플레이 실행 환경을 설정하고 게임을 실행합니다.
